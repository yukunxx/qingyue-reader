# 产品设计文档：TXT 阅读器（MVP）

> 版本：v0.1（MVP 规划）　|　状态：草案

## 1. 产品概述

一个运行在浏览器中的轻量电子书阅读器。MVP 阶段聚焦于 **TXT 纯文本阅读**，跑通"导入 → 阅读 → 记住进度"的最小闭环，优先保证阅读体验和中文文本兼容性。

- **形态**：Web 应用（浏览器内使用，纯前端，无需后端）
- **首发格式**：TXT（后续再扩展 EPUB）

## 2. 产品目标

**MVP 核心目标**：让用户能方便地打开本地 TXT 文件，舒服地阅读，并在下次打开时自动回到上次的位置。

**非目标（MVP 明确不做）**：

- EPUB / PDF 等其他格式
- 目录 / 章节导航（TXT 无原生章节概念）
- 云同步、多设备
- 书签 / 高亮、全文搜索
- DRM、笔记导出、语音朗读

## 3. 目标用户与场景

- **目标用户**：主要阅读中文 TXT 小说的普通用户，希望在电脑浏览器里快速打开并阅读本地文本文件。
- **典型场景**：
  1. 用户拖入一个下载好的小说 TXT → 立即开始阅读。
  2. 阅读中途关闭页面 → 下次打开自动恢复到上次位置。
  3. 夜间阅读 → 切换到夜间主题。

## 4. 功能范围

### 4.1 核心功能（P0，MVP 必须完成）

| 模块 | 功能 | 说明 |
|---|---|---|
| 导入 | 拖拽 / 文件选择导入 TXT | 支持多文件导入 |
| 导入 | 编码探测 | 自动识别 UTF-8 / GBK，避免中文乱码 |
| 书架 | 书籍列表 | 展示书名、最近阅读时间 |
| 书架 | 删除书籍 | 移除已导入的书 |
| 书架 | 最近阅读排序 | 最近读的排前面 |
| 阅读 | 分页阅读 | 大文件分页渲染，避免卡顿 |
| 阅读 | 字号 / 行距调节 | 适配不同阅读习惯 |
| 阅读 | 主题切换 | 日间 / 夜间（护眼）主题 |
| 阅读 | 进度记忆 | 记住阅读位置，下次自动恢复 |
| 持久化 | 本地存储 | 书内容与进度存 IndexedDB，刷新不丢 |

### 4.2 后续迭代（P1，MVP 之后）

- EPUB 格式支持
- 简易章节识别（按「第 X 章」正则切分）
- 书签 / 高亮划线
- 单本书内全文搜索
- 阅读时长统计

### 4.3 明确不做（长期或另行评估）

- PDF、MOBI 等格式
- 云同步、多设备
- DRM（加密书）支持
- 笔记导出、词典、社交分享
- 语音朗读（TTS）

## 5. 关键技术方向

- **技术栈**：Vite + React + TypeScript
- **存储**：IndexedDB（可容纳 MB 级文本文件，localStorage 容量不足）
- **核心技术点**：
  1. **编码探测**：优先 UTF-8，失败回退 GBK，解决中文小说乱码问题。
  2. **大文件分页渲染**：只渲染当前屏附近内容，避免上百万字一次性渲染导致卡死。

## 6. 关键决策记录

| 决策 | 结论 | 原因 |
|---|---|---|
| 平台形态 | Web 应用 | 跨平台、免安装、易分享 |
| 首发格式 | 仅 TXT | 降低复杂度，EPUB 解析/分页成本高，留待后续 |
| 目录/章节 | MVP 不做 | TXT 无原生章节，且可通过后续正则识别廉价补上 |
| 后端 | 不需要 | 纯前端 + 本地存储即可满足 MVP |

## 7. 里程碑

1. **M1**：项目脚手架 + 导入 TXT + 编码探测，正确显示文本。
2. **M2**：书架、删除、进度记忆（IndexedDB）。
3. **M3**：阅读器完善（分页、字号、行距、主题）+ 大文件渲染优化。
